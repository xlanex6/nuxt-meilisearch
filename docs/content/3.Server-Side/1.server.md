# Meilisearch on the server

::caution
Since v1.4.0 the server client is `$meilisearch(event)`. Pass the H3 event so Nitro can read the runtime config for that request.
::

## Configuration

Enable server usage and set an API key with admin access. The admin key stays in the private runtime config.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  meilisearch: {
    serverSideUsage: true,
    adminApiKey: '<your_secret_key>',
  },
})
```

::warning
`adminApiKey` must be a key with admin access. Do not put that key in `searchApiKey` or any public config.
::

## Usage

`$meilisearch` is auto-imported in server routes and is fully typed.

```ts [server/api/books.post.ts]
export default defineEventHandler(async (event) => {
  const body = await readBody(event)

  return $meilisearch(event).index('books').addDocuments(body)
})
```
