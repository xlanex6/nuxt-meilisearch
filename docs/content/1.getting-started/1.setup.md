## Installation

Add `nuxt-meilisearch` with the Nuxt CLI:

```bash
npx nuxi@latest module add nuxt-meilisearch
```

Or install it with your package manager, then register the module:

```bash
# npm
npm install nuxt-meilisearch

# yarn
yarn add nuxt-meilisearch

# pnpm
pnpm add nuxt-meilisearch
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    'nuxt-meilisearch',
  ],
})
```

## Basic setup

::badge
Client side only
::

Provide the host URL and a search-only API key.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    'nuxt-meilisearch',
  ],
  meilisearch: {
    hostUrl: 'http://my-meilisearch-server.domain.com',
    searchApiKey: '<your_search_key>',
  },
})
```

## Advanced setup

::badge
Client and server
::

`serverSideUsage` exposes `$meilisearch(event)` in Nitro routes. That path needs an admin API key. `instantSearch` loads Vue InstantSearch and an optional theme (`satellite`, `reset` or `algolia`).

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    'nuxt-meilisearch',
  ],
  meilisearch: {
    hostUrl: 'http://my-meilisearch-server.domain.com',
    searchApiKey: '<your_search_key>',
    adminApiKey: '<your_admin_key>',
    instantSearch: true, // default: false
    serverSideUsage: false, // default: false
  },
})
```

Theme details are on the [InstantSearch widget styling page](https://www.algolia.com/doc/guides/building-search-ui/widgets/customize-an-existing-widget/vue/#style-your-widgets). Client options for Instant Meilisearch are documented in the [instant-meilisearch repository](https://github.com/meilisearch/meilisearch-js-plugins/tree/main/packages/instant-meilisearch).
