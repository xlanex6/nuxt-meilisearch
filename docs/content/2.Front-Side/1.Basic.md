# Basic

Search from your components with the composables this module auto-imports.

## useMeiliSearch

Search one index. `books` below is the index uid.

```vue
<script setup>
const { search, result } = useMeiliSearch('books')

onMounted(async () => {
  await search('harry')
})
</script>
```

### `search(query: string, options?: SearchParams)`

Returns the search response. Query options are listed in the [search API reference](https://www.meilisearch.com/docs/reference/api/search#body).

### `result`

Holds the latest response and updates on every `search` call. The response shape is documented in the [search response reference](https://www.meilisearch.com/docs/reference/api/search#response).

::note
The same value is stored with `useState('<index>-search-result')`, so another component can read it without searching again. For the `books` index the key is `books-search-result`.
::

```vue
<script setup>
const booksResult = useState('books-search-result')
</script>
```

## useAsyncMeiliSearch

Same search as `useMeiliSearch`, with a `data` ref that works during SSR and a `refresh` function to run it again.

`index` is required. `query` is optional. Pass `params` for any [search option](https://www.meilisearch.com/docs/reference/api/search#body).

```ts
const { data, refresh } = await useAsyncMeiliSearch({
  index: 'books',
  query: 'harry',
  params: {
    limit: 2,
  },
})
```

## useMeiliSearchRef

Returns the shared Meilisearch client built from the public host and search key.

```vue
<script setup>
const meilisearch = useMeiliSearchRef()
</script>
```
