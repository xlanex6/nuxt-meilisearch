# DevTools tab

With [Nuxt DevTools](https://devtools.nuxt.com/) enabled, the module adds a Meilisearch tab. The tab embeds `hostUrl` in an iframe, so the instance UI has to be reachable from the browser.

## Admin demo

The embedded Meilisearch mini-dashboard asks for an admin key before it shows indexes and documents.

## Tasks

Task inspection inside the tab is not implemented yet.
